# Creative Lessons

This file keeps practical lessons from rendered drafts.

## Current Rules

- Hooks need TikTok-native tension, not generic ad phrasing.
- Ukrainian copy must sound natural, not translated.
- A video needs a real scenario, not one static template repeated.
- CTA should be a designed final screen.
- Screen recordings should be full product moments, not cropped inserts.
- Static images must have a role and light motion.
- Pexels is used to expand the visual library, not as blind bulk download.

## Subtitle Lessons

- Use either full karaoke/TikTok text or short bullets.
- Bullet subtitles should carry only key words or key phrases.
- Large UI scenes need subtitle placement checks.
- Text should be a bit more expressive in size, but not cover important visuals.

## Visual Lessons

- Too much natal chart footage becomes repetitive quickly.
- Interface recordings are useful, but only when readable.
- CTA backgrounds without baked text are more reusable.
- Product-led videos need clean product moments, not accidental zoomed UI.
- Emotional videos can become too dark/mystic; keep some human clarity.

## UBT008 Notes
