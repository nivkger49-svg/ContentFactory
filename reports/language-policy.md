# Language Policy

## Production Language

Each project must define its production language before generating hooks, voiceovers, subtitles, CTA text, and ad copy.

Record the project language in the project brief or storyboard notes, for example:

```text
production_language: Ukrainian
market: Ukraine
```

## Rule

Production-facing creative materials must use the selected project language consistently:

- hooks;
- subtitles;
- voiceovers;
- CTA text;
- on-screen labels;
- ad copy;
- landing-specific creative text.

## Internal Notes

Internal planning notes may use any convenient language, but every asset that reaches users must be rewritten into the selected production language before testing or publishing.

## QA Checklist

Before rendering or publishing, check:

```text
No accidental mixed-language production copy in video/subtitles/voice/CTA/ad text.
```

If a hook or script starts in a different language, convert it and store the final tested version in the project language.
