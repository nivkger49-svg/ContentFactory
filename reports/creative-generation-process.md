# Creative Process Note

Future creative generation should use a two-step process:

1. Hook sprint only:
   - Ask each model for 10-20 hooks.
   - No full scripts yet.
   - Force different mechanics: curiosity, pain, anti-horoscope, money, relationships, identity, night-scroll, UGC gossip, myth busting.
   - Filter for natural Ukrainian and non-ad feeling.

2. Skeleton only for winners:
   - first 3 seconds,
   - visual idea,
   - voiceover,
   - CTA,
   - funnel route,
   - risk.

This prevents spending time polishing weak hooks.
